# EndlessRunner3D

A 3D Endless Runner game built in Unity. 

### Features

- **Infinite Procedurally Generated Track**: The world spawns dynamically as you run.
- **Dynamic Obstacles**: Dodge obstacles in your path to survive.
- **Collectibles**: 
  - **Coins**: Collect coins to increase your score.
  - **Shields**: Protects the player from one collision.
  - **Magnets**: Automatically attracts nearby coins to the player.
- **Customizable 3D Characters**: Uses ithappy Creative Characters FREE assets for a vibrant and customizable player model.

### Assets Used

- `ithappy/Creative_Characters_FREE`
- Boxophobic Skybox Cubemap Extended
- Various custom materials for Track, Coins, Shields, and Obstacles
